[[introduction]]
= Choose where your process starts

The same supply process can start at different points. Each scenario below shows the complete exchange as a sequence diagram. Identifiers are named by their business term, not by XML element name; hover a link to see the element path, or follow it to the element in the syntax of that transaction.

[NOTE]
====
*Main linking rule.* Use the *Purchase order reference* where a buyer order exists. Without a buyer order, use the seller's *Sales order reference*.
====
