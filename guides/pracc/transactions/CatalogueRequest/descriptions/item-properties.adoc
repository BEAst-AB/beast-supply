= Additional Item Properties

Additional properties are meant for product properties that cannot be sent in any of the defined elements in PreAward Catalogue. Additional properties 
consist of the Name of the property and the actual Value.

.Example of additional properties:
* Color
* Nutrition +
Stated with amount per 100 g/ml.
* Genetically modified +
Legal values: True, False
