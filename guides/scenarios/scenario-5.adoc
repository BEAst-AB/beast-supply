[[scenario-5]]
= Scenario 5 – From despatch advice

_Delivery note and invoice only — bulk call-offs against a catalogue_

Scenario 5 covers bulk call-offs against a catalogue where no order, order response or order agreement is exchanged. Each delivery is described by its own advanced despatch advice, and the sales order id is the only order-level key. Original example: sales order 123, lines 1–3 (gravel 8/16, 0/8, 16/32), each delivered on its own despatch advice.
