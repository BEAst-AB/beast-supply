[[scenario-3]]
= Scenario 3 – From order

_Single order, no blanket order — the order id is the only frame_

Scenario 3 starts with a single order against the catalogue. There is no blanket order and no order agreement — the order response is the seller’s confirmation.

[[scenario-3-transactions]]
== Transactions and identifiers

Transactions in scope: Catalogue (T19), Catalogue response (T58), Order (T01), Order response (T76), Advanced despatch advice (T120), Receipt advice (T128), Invoice (Peppol BIS Billing 3.0).

== Reference matrix

An empty cell means the reference is not used in that transaction; references that are not used at all in this scenario are left out. The sales order id and sales order line id travel along as secondary keys but are not needed for matching — the purchase order id is the primary key.
