[[scenario-1]]
= Scenario 1 – All transactions

_From request for quotation to invoice — the purchase order id is the primary link_

Scenario 1 covers the complete document chain: a pre-award step (request for quotation and quote), a catalogue with catalogue response, a blanket order used as the contract, call-off orders with order response and order agreement, and the delivery documents ending with the invoice. The weight statement is not part of the scenario.

[[scenario-1-transactions]]
== Transactions and identifiers

Transactions in scope: Pre-award catalogue request (T035), Pre-award catalogue, Catalogue (T19), Catalogue response (T58), Order (T01) used as blanket order, Order (T01), Order response (T76), Order agreement (T110), Advanced despatch advice (T120), Receipt advice (T128), Invoice (Peppol BIS Billing 3.0).
