[[scenario-1]]
= Scenario 1 – All transactions

_From request for quotation to invoice — the purchase order id is the primary link_

Scenario 1 covers the complete document chain: a pre-award step (request for quotation and quote), a catalogue with catalogue response, a blanket order used as the contract, call-off orders with order response and order agreement, and the delivery documents ending with the invoice. The weight statement is not part of the scenario.

[NOTE]
====
*Blanket order as contract reference.* CONOID is the value later used in `cac:ContractDocumentReference` on the order agreement and the invoice. Confirm with trading partners that a confirmed blanket order is accepted as a contract reference.
====

[NOTE]
====
*Purchase order id present.* OID is carried at header level in every document and the order line number at line level. The sales order id travels along as a secondary key but is not needed for matching.
====
