[[scenario-4]]
= Scenario 4 – From order agreement

_Telephone order in, order agreement back — the sales order id is the key_

In scenario 4 the buyer orders by telephone, so no electronic order exists. The seller confirms with an order agreement, whose identifier is globally unique and is used by the buyer as the order number.

[[scenario-4-transactions]]
== Transactions and identifiers

Transactions in scope: Catalogue (T19), Catalogue response (T58), Order agreement (T110), Advanced despatch advice (T120), Receipt advice (T128), Invoice (Peppol BIS Billing 3.0).
