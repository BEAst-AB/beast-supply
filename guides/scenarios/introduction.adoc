[[introduction]]
= Introduction

This page describes five scenarios for exchanging BEAst Supply documents over Peppol. All scenarios use the same chain of transactions; they differ in where the chain starts. For each scenario the page shows which identifiers every transaction carries, and a reference matrix that names the syntax element used for each reference, with a link to its definition in the syntax.

Except where noted, the catalogue and catalogue response precede every scenario. They carry the contract reference and the item identifiers — standard item id and seller item id — that all later documents reuse.

NOTE: The sales order line id in the examples is the plain line number (10). Whether it should follow the pattern sales order number : line number (e.g. `112233:10`) is an open point, see <<open-points>>.

[[linking-rule]]
== Linking rule

Every downstream document must be traceable to one commercial commitment. Apply the levels in order and use the first one that is populated.

[cols="1,3s,4,5",options="header"]
|===
|# |Precedence |When it applies |Carried in
|1 |Purchase order id exists |The buyer issued an order (scenario 1, 2, 3) |Header: `cac:OrderReference/cbc:ID` = 110408542 +
Line: `cac:OrderLineReference/cbc:LineID` = 1
|2 |No purchase order id — use the sales order id |An order agreement or a despatch advice starts the chain (scenario 4, 5) |Header: `cbc:SalesOrderID` (order agreement), `cac:OrderReference/cbc:SalesOrderID` (invoice) +
Line: `cac:OrderLineReference/cbc:SalesOrderLineID`
|3 |Contract or blanket order as the frame |Whenever a blanket order or contract exists |`cac:ContractDocumentReference/cbc:ID` = 4832423 +
`cac:ReferencedContract/cbc:ID` in the catalogue
|4 |Item identity on every line |All scenarios |`cac:StandardItemIdentification/cbc:ID` = 05704066204093 +
`cac:SellersItemIdentification/cbc:ID` = 8522173
|===

[NOTE]
====
*Consequence for scenario 4 and 5.* The seller owns the identifier. The buyer must be able to accept a sales order number as the only order-level key on despatch advice, receipt advice and invoice, and to match it against a contract or catalogue reference.
====
